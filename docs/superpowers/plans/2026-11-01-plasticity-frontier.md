# Prepared Learning Joint Frontier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the blueprint's complete local research program with verified joint frontiers, fair learned-prior comparisons, reproducible inference, and measured operational tradeoffs.

**Architecture:** A small `prepared_learning` Python package separates geometry, scalar QPs, verification, observed data, evaluator truth, methods, and experiment records. Exact fixtures and independent checks gate all later experiments; immutable protocols and keyed data gate confirmation. Statistical and performance stages may conclude that the correctly implemented mechanism has no comparative advantage.

**Tech Stack:** Native CPU Python, NumPy, SciPy, standard-library `unittest`, `fractions`, JSON/JSONL/CSV and hashing; Matplotlib only for scientific reporting. Discover compatible versions and lock actual wheels in Task 1.

**Spec:** [Approved design](../specs/2026-11-01-plasticity-frontier-design.md); read alongside [blueprint](../../blueprint.md) and [source audit](../reviews/2026-11-01-source-audit.md).

## Global Constraints

- Core arithmetic uses CPU float64; independent complex-step checks use complex128.
- Main scientific runs use depth L >= 2, eta = 1.0, and loss ||Xw-y||^2/(2n).
- Every network matrix entry is an independent trainable scalar, including initialized zeros; there are no biases, tied weights, residual paths, frozen features, or fixed normalization factors.
- Core tasks have mean zero, PSD second moment S with trace 1, independent Gaussian N(0,I_d) input rows, and independent mean-zero noise of variance sigma2 >= 0.
- Primary risk is expected squared coefficient error, equivalently noiseless isotropic prediction MSE; fresh-label MSE additionally includes sigma2.
- Preserve the original blueprint, PDF, ZIP, extracted source snapshot, and recorded failed diagnostics unchanged.
- Methods receive only their declared prior assets and observed context/source data; evaluator truth never enters learned preparation, adaptation, or validation selection.
- A canonical network and its matching compact direct map must produce the same first-step coefficient within reported numerical error.
- Float64 primal/dual values are diagnostics; only exact rational checks or rigorous roundoff enclosures may be called certificates.
- Confirmation uses frozen scientific inputs and fixed endpoint-specific sample counts; pilot data are excluded, and outcome-based sample extension is forbidden.
- Faithful recovery may change batching or checkpoint cadence; changes to code, dependencies, prior assets, or scientific configuration require a new confirmation identity.
- Record methodological amendments before changing population, coordinates, learning rate, primary metric, information access, baseline class, confirmatory configuration, or inference procedure.
- The core runs locally without external datasets, API keys, trained weights, or a GPU.

## Review Focus

- Tiny valid gains, repeated minima, and full-rank Z targets must retain intended support and use the correct constructor/count; regression tests in Tasks 3, 5, 6.
- A reused initializer, sequential parameter update, or evaluator-truth access must fail validation rather than manufacture an advantage; tests in Tasks 3, 7, 8, 11.
- Singular/noiseless posterior and empirical-QP limits must remain valid without an undisclosed ridge or false dual certificate; tests in Tasks 4, 6, 8.
- An interruption, corrupt block, method failure, or changed scientific identity must never duplicate/drop pairs or mix results; tests in Tasks 9, 11, 15.
- Endpoint counts, held-out selection, and preparation-level uncertainty must survive analytic versus nested modes and negative results; tests in Tasks 1, 9, 10, 11, 15.
