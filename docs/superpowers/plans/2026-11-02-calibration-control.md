# Calibration Control Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. This bounded plan has one implementation task; workers do not spawn subagents.

**Goal:** Verify complete calibration controls by canonical byte hashes during report/replay reconstruction without retaining their aggregate JSON trees or weakening integrity.

**Architecture:** The unchanged public finalizer publishes a complete canonical sidecar and additive versioned frozen binding after its existing scientific checks. Report inventory verifies the original and canonical bytes and admits those two files as hash-only assets; raw worker reconstruction remains authoritative. Native finalizer/validator parsing stays admitted, while old bindings retain their existing report behavior.

**Tech Stack:** Existing locked Python, standard-library JSON/hashlib/filesystem primitives and unittest; no dependencies.

**Spec:** `docs/superpowers/specs/2026-11-02-calibration-control-design.md`, subordinate to sections 9–11 of `docs/superpowers/specs/2026-11-01-plasticity-frontier-design.md`.

This is a root-builder proposal, not evidence of completed implementation or a newly approved scientific claim. Execution uses the established current-branch workflow and meaningful local commits; no push, merge, new worktree or science execution is included.

## Global Constraints

- Keep public signatures and `records.content_hash` unchanged; preserve scientific maps, all methods/controls/candidates/failures, raw records, schedules, sample counts and gates.
- Constants remain **256 semantic JSON / 64 native parse / 64 MiB base / 16 array factor**, with replay's **two copies** and **half currently available RAM**; an explicit cap may only lower the reserve.
- New frozen format is exactly `prepared_calibration_canonical_v1`; existing benchmark schema version 1 and report schema `benchmark_raw_refs_v2` remain. Missing format binding means legacy; present invalid binding fails closed.
- Preserve original `calibration_path` and `calibration_sha256`; never patch/rebind old manifests, controls or source identities. Export all unknown fields without filtering.
- Actual14 probe is capacity planning on excluded exploratory observations; full196 G9 is unrun. No actual G9 failure or whole-pipeline success is inferred.
- All source work must be committed and reviewed before a genuinely fresh G6; old source36 G6 remains `INSENSITIVE_OR_UNSUITABLE`. No roots or source/statistical counts are allocated here.

## Review Focus

- Canonical serialization drift on Unicode, escapes, floats/negative zero and unknown nested fields must fail exact byte/hash parity; Task 1 pins the encoder contract.
- Missing/partial/version-confused references and byte-only edits must never activate hash-only admission or silently fall back; Task 1 pins strict binding and tamper rejection.
- Interrupted publication, an existing manifest or conflicting sidecar must preserve original bytes and never publish a false finalized control; Task 1 injects these failures.
- Mixed semantic/hash-only inventories must retain complete hashes and charge semantic workers, metadata and two replay copies; Task 1 exercises every admission entry point.
- Rebuilt raw schedules/selected identities and legacy source recovery must survive the new path unchanged; Task 1 compares legacy/new scientific output and negative schedule/request cases.

### Task 1: Publish and verify canonical full calibration controls with bounded report admission

**Files:**

- Modify `src/prepared_learning/benchmark.py`: finalizer/validator integration, private canonical writer and binding verifier; no producer/estimator changes.
- Modify `src/prepared_learning/reporting.py`: asset roles, guard counters/aggregation, complete control inventory and new-format aggregate verification path.
- Modify `src/prepared_learning/cli.py`: catch the newly possible benchmark-validator `ReportingResourceLimit`, emit a machine-readable `LOCAL_RESOURCE_LIMIT` decision and nonzero status, without creating the fixed output directory or changing its manifest.
- Modify `tests/test_benchmark.py`, `tests/test_reporting.py`, `tests/test_replay.py`: focused tests and explicitly synthetic fixture helpers.
- Read `src/prepared_learning/records.py` and `src/prepared_learning/_replay.py` as contracts; do not change them. If a production replay change proves necessary, return the concrete reason to the controller before expanding source scope.

**Interfaces:**

- Preserve `finalize_benchmark_manifest(calibration_path, manifest_path, campaign_output)`, `validate_campaign_manifest(manifest, *, manifest_path=None)`, `_guard_paths(paths, *, phase, copies=1, object_bytes=0, streaming=False, json_factor=REPORT_JSON_FACTOR)`, `_input_paths(entry, *, retained_bytes=0)` and report/replay public APIs.
- Add in `benchmark.py`: `_canonical_calibration_path(calibration_path: Path) -> Path`; `_write_canonical_calibration(evidence: dict, path: Path, expected_sha256: str) -> None`; `_verify_calibration_control(frozen: dict) -> tuple[Path, Path] | None`. The last returns `(original, canonical)` only after strict version/path/digest validation and streaming both proofs; returns `None` only when the key is absent. It never parses controls or writes files. Reuse reporting's chunked `_sha` and native guard through local imports, avoiding duplicated policy and import-time cycles.
- Add in `reporting.py`: `_input_assets(entry, *, retained_bytes=0)` yielding `(Path, role)` with role exactly `semantic` or `hash_only`; `_guard_assets(assets, *, phase, copies=1, object_bytes=0, streaming=False, json_factor=REPORT_JSON_FACTOR) -> dict`. `_guard_paths` wraps paths as semantic assets. `_input_paths` strips roles from `_input_assets` for callers that need paths.
- Extend `_empty_scale`/guard evidence with `hash_only_files`, `hash_only_bytes`, `semantic_json_bytes`, `max_semantic_json_bytes`. Preserve inclusive `json_bytes`, `max_json_bytes`, largest-file/file-count and inventory fields. `json_working_bytes` uses semantic totals/maxima; `_guard_inputs` aggregates semantic working bytes and all inventory costs with its existing replay multiplier.
- Add exactly `frozen.calibration_control = {'format': 'prepared_calibration_canonical_v1', 'path': str(canonical_path), 'source_sha256': original_byte_sha256}`. The canonical file SHA equals existing `frozen.calibration_sha256`; no second unrelated content-hash namespace is introduced.
