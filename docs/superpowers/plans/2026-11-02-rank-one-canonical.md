> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reconstruct the mathematically unique common F/Z rank-one point after existing successful admission, preserving failure and correction evidence.

**Architecture:** The oracle frontier owns the structural decision because it knows the exact supplied spectrum and production branch geometry. The generic solver only exposes its original admitted candidate for exact correction accounting. Existing final quality, independent Z comparison, frontier uncertainty and B04 tie rules remain authoritative.

**Tech Stack:** Existing locked Python, NumPy, SciPy and unittest; no new dependency.

**Spec:** `docs/superpowers/specs/2026-11-02-rank-one-canonical-design.md`, subordinate to section 11 of the approved `2026-11-01-plasticity-frontier-design.md`.
