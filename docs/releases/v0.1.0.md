# Plasticity Frontier v0.1.0

First public release of the research code, original mathematical inputs and
completed controlled study of preparing zero-output networks for one-step learning.

- **Primary result:** expected coefficient error 0.754794 → 0.706105 across 31
  independent source preparations; descriptive reduction 6.45%. Absolute paired
  improvement 0.0486885, approximate 95% Student interval [0.0424602, 0.0549168].
- **Comparisons:** all 14 methods on 2,048 shared tasks, including six direct-map
  equality controls, ridge and empirical Bayes. Empirical Bayes gets lower error
  in that separate fixed-cohort panel; no network-representation advantage is established.
- **Included:** three README figures in PNG/SVG, underlying CSVs, a standard-library
  result check, a figure rebuild script, the original matched clean-replay receipt,
  reference mathematics, source code and tests.
- **Licensing:** AGPL-3.0-only software; CC BY 4.0 original writing, figures and
  result compilations, following the owner's recent research repositories.

The result is scoped to small Gaussian linear-regression tasks, the declared
norm/parameter budgets and one learning update. The executed norm tolerance and
all diagnostic limitations remain in the full verdict. Nonlinear-network,
real-world-transfer and energy advantages are unproved.

The compact result ZIP can verify the published numbers and regenerate the
figures. The wheel contains the research and reference-check modules. For the
complete code, original PDF/ZIP, configurations and fixtures, use GitHub's source
archive or clone the repository. Full protected replay additionally requires the
original local raw stores, frozen arrays, wheel cache and execution packages;
those large artifacts are not part of this release. The archived receipt records
a matched same-machine replay, not a new independent sample.
